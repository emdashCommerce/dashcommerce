Setup before you start (fresh store, webhooks, keys)
  1. Keys (test mode): Stripe sk_test_ and pk_test_; Paystack rk_test_ (or sk_test_) and whsec_ if you have one. Paste them only into the admin form.
  2. Fresh store, terminal 1: 
    cd ~/Projects/DashCommerce/.worktrees/FIK-57-paystack-e2e
git pull && npx bun@1.4.3 install
(cd packages/core && npx bun@1.4.3 run build) && (cd packages/paystack && npx bun@1.4.3 run build)
cd packages/starter && rm -f data.db data.db-shm data.db-wal
npx emdash init && node ../core/dist/cli/merge-seed.js && npx emdash seed --on-conflict=update
git checkout -- .emdash/seed.json emdash-env.d.ts
SITE_URL=http://localhost:4321 npx astro dev --port 4321
  3. Sign in: http://localhost:4321/_emdash/api/setup/dev-bypass?redirect=/_emdash/admin. Add a KES 1,000.00 price to Design Templates; enable KES and make it the default.
  4. Webhooks: terminal 2 node docs/testing/capture-webhooks.mjs · terminal 3 ngrok http 4322 (Paystack test webhook URL: https://<ngrok>/_emdash/api/plugins/dashcommerce/checkout/webhook?provider=paystack) · terminal 4, once: stripe login, then bash docs/testing/stripe-listen.sh from the worktree root (it names the events newer Stripe CLIs require; the whsec_ it prints is Stripe's webhook secret).
  5. Full reference: docs/testing/payments-e2e.md on the branch.
